## 🌱 درباره دست‌خوش

**دست‌خوش** برای ثبت و مرور هزینه‌های روزمره طراحی شده است؛ بدون فرم‌های شلوغ و مراحل اضافه.

مبلغ را وارد کن، توضیحش را بنویس و هزینه را ذخیره کن. با مرور تاریخچه هم راحت‌تر ببین پولت کجا خرج شده است.
.

<a id="features"></a>

## ✨ قابلیت‌ها

### 📝 ثبت هزینه
- فرم دومرحله‌ای برای ورود مبلغ و توضیحات.
- نمایش خوانای مبلغ به تومان.
- مدیریت وضعیت فرم و پیام‌های موفقیت و خطا.

### 🧾 مرور هزینه‌ها
- نمایش تاریخچه هزینه‌های ثبت‌شده.
- دسترسی به مبلغ و توضیحات هر هزینه در فهرست.

### 🎨 رابط کاربری
- طراحی با **SwiftUI** و تم اختصاصی **AppTheme**.
- پشتیبانی از چیدمان **راست‌به‌چپ**.
- نمایش ارقام فارسی و تفکیک سه‌رقمی مبالغ.
- انیمیشن‌های رابط کاربری با درنظرگرفتن تنظیم **Reduce Motion**.

## 🛠 فناوری‌ها و ابزارها

| بخش | فناوری |
| :--- | :--- |
| زبان برنامه‌نویسی | Swift |
| رابط کاربری | SwiftUI |
| معماری | MVVM |
| تزریق وابستگی | Swinject |
| مدیریت پکیج‌ها | Swift Package Manager |
| محیط توسعه | Xcode |

### چرا این ترکیب؟

**SwiftUI** برای ساخت رابط کاربری واکنش‌گرا، **MVVM** برای جداسازی منطق نمایش از رابط کاربری و **Swinject** برای مدیریت وابستگی‌ها استفاده شده‌اند.

<a id="getting-started"></a>

## 🚀 اجرای پروژه

### پیش‌نیازها

- سیستم‌عامل **macOS**
- نسخه سازگار **Xcode** با تنظیمات پروژه
- شبیه‌ساز iOS یا آیفون سازگار با Deployment Target پروژه

### ۱. دریافت سورس

```bash
git clone https://github.com/HomanYosefi/DastKhosh-App-iOS.git
cd DastKhosh
```

### ۲. بازکردن پروژه

فایل پروژه را در Xcode باز کن:

```bash
open DastKhosh.xcodeproj
```

### ۳. دریافت وابستگی‌ها

وابستگی پروژه از طریق **Swift Package Manager** دریافت می‌شود:

- [Swinject](https://github.com/Swinject/Swinject)

اگر دریافت پکیج‌ها خودکار انجام نشد، از منوی Xcode استفاده کن:

```text
File → Packages → Resolve Package Versions
```

### ۴. اجرا

یک شبیه‌ساز یا دستگاه انتخاب کن و با **⌘R** برنامه را اجرا کن.

> برای اجرا روی آیفون واقعی، در بخش **Signing & Capabilities** تیم توسعه خودت را انتخاب کن.
